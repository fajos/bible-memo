## 2. Description of the Application

Selah Scripture Memory is a free, offline-first educational and spiritual utility intended to assist users in reading, studying, meditating upon, and memorizing the Holy Scriptures. Key capabilities include:
- Spaced Repetition System (SuperMemo SM-2) review scheduling.
- Interactive study modes (Scripture Typer, Word Scramble, Fill-in-the-Blank, First Letter Prompts, and Selah Meditation).
- Bible quizzes and trivia challenges.
- Local data backup and export.
